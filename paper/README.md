# Paper Assets

This directory contains the paper-facing artifacts curated for the publish branch.

## Included files

- `acmmm_mm2026_anonymous.pdf`
  The anonymized ACM MM paper build used as the main reference snapshot.
- `acmmm_mm2026_anonymous.tex`
  The matching LaTeX source used for the packaged paper version.
- `acmmm_mm2026_refs.bib`
  The BibTeX file associated with the packaged paper source.
- `figures/`
  Generated main-paper figures in PNG, PDF, and SVG form, plus a short caption file.
- `supplementary/supplementary_package_20260402.zip`
  The supplementary package snapshot kept with the paper release.

## Intent

The publish branch keeps only the paper assets that are directly useful for reading, citing, or presenting the project. It does not mirror the full local writing workspace or all intermediate LaTeX build products.
